04 / DIMENSIONALITY REDUCTION AND CLASSIFICATION

Why this baseline? What does it miss?

A pragmatic first classifier — strong enough for a course demonstration, but not a full astronomical detection pipeline.

WHY RANDOM FOREST
  • Handles nonlinear relationships between statistical features.
  • Combines multiple trees to reduce dependence on a single split.
  • Works naturally with a small, tabular feature matrix.
  • Supports class balancing and repeatable training settings.
LIMITATIONS TO EXPLAIN
  • Summaries discard the order and spacing of transit dips.
  • No Box Least Squares or explicit orbital-period search.
  • Very few positive examples make generalization difficult.
  • Predicted probabilities are not calibrated planet certainty.
Viva-ready answer: “We used ten statistical features as an interpretable baseline; a future version would add transit depth, duration, periodicity, and domain-specific validation.”

05 / MODEL IMPLEMENTATION AND VALIDATION

From code to a reproducible ML pipeline

The actual project architecture in a few lines of Python.

# Ten statistical features per light curve
X_train = extract(train_flux)

model = Pipeline([
  ('imputer', SimpleImputer(
      strategy='median')),
  ('classifier', RandomForestClassifier(
      n_estimators=120,
      class_weight='balanced',
      random_state=42, n_jobs=-1))
])
model.fit(X_train, y_train)
pred = model.predict(extract(test_flux))

WHY THIS MATTERS

The positive class is the mission.

  • Prioritize recall to understand missed hosts.
  • Use precision to assess false alarms.
  • Use F1 for a combined positive-class score.
  • Inspect the full confusion matrix.

PROJECT CONCLUSION & FUTURE SCOPE

What we built — and what comes next

A complete educational ML workflow with transparent boundaries and a path toward more scientifically informed models.

IMPLEMENTED
  • CSV ingestion and label/flux validation.
  • Interactive light-curve visualization.
  • Ten-feature extraction and median imputation.
  • Balanced Random Forest classification.
  • Test evaluation and CSV prediction export.
FUTURE ENHANCEMENTS
  • Transit-specific depth, duration, and periodicity features.
  • Box Least Squares and astronomical vetting.
  • Cross-validation, tuning, and calibrated probabilities.
  • More positive examples and external datasets.
  • Model explainability and error analysis.
Final takeaway: Machine learning can help prioritize interesting light curves, but classification alone does not establish an exoplanet discovery.
